# Assignment Deadline Tracker

## Project Goal

The Assignment Deadline Tracker is a Java command-line application designed to help students organize assignments from different courses, keep track of due dates, and monitor their progress.

## MVP Scope

The first version of the project will include:

- Adding assignments with a name, course, and due date.
- Viewing assignments sorted by due date.
- Marking assignments as completed.
- Identifying upcoming and overdue assignments.
- Saving and loading assignments from a file.

## Future Plans

Features planned for future versions include:

- Adding priority levels to assignments.
- Generating weekly summaries of completed and pending assignments.
- Filtering assignments by course or completion status.

## Tech Stack

- **Language:** Java
- **Libraries:** Java standard library, including `java.time`, `java.util`, and `java.nio.file`.
- **Data Storage:** Local file storage for saving assignment information.
- **Development Tools:** Visual Studio Code and JDK 27.
- **Version Control:** Git and GitHub.
- **External Data Sources:** None.
